## 1. Four-Tier Evidence Grading Standard (四级证据查账标准)

Every financial metric across our case teardowns is explicitly labeled with one of four evidence tiers ([Full Methodology](https://www.jimmydecodes.com/en/method/)):

1. **`[Verified]` / `【核实】`**: Direct read-only payment processor API sync (Stripe, RevenueCat, Polar, Paddle, or Shopify via TrustMRR), audited public exchange filings (SEC 10-K / HKEX / A-share annual reports), or live official pricing pages.
2. **`[Self-Reported]` / `【自报】`**: Founder social posts, interviews, or seller-submitted marketplace listings without live payment-API verification (recorded as-is, never treated as audited fact).
3. **`[Third-Party]` / `【第三方】`**: External research and analytics platforms (Similarweb, Ahrefs DR, G2, Trustpilot, government statistics) with logged sampling dates.
4. **`[Estimate]` / `【估算】`**: Reproducible unit-economics and AI compute cost models calculated from public API pricing and stated assumptions.
